O jogador escolhe uma classe, equipa um item e toma decisões para enfrentar a
criatura que ameaça a vila de **Valkir**.

## Funcionalidades

- Três classes com atributos diferentes;
- Escolha de item inicial;
- Combate por turnos;
- Chance de golpe crítico e fuga;
- Validação das escolhas digitadas;
- Caminhos e finais diferentes;
- Execução inteiramente pelo terminal.

## Classes

| Classe | HP | Ataque |

| Assassino das Sombras | 22 | 20 |
| Paladino Carmesim | 30 | 14 |

## Como executar

Na raiz deste repositório, entre na pasta do projeto:

```bash
cd 05_projetos/rpg-valkir-python
```

```bash
python main.py
```

No Windows:

```powershell
py main.py
```

O projeto utiliza somente módulos da biblioteca padrão do Python.
